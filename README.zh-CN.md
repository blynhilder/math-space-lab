# 数学互动实验室

将曲面、三维坐标、矩阵变换和立方晶格变成可以旋转、调参、观察的学习工具，并提供 MCP 接口连接兼容的聊天客户端。

运行步骤见英文 README：先安装并构建 math-plugin 的 bridge，再运行 scripts/build-ui.py，最后构建和启动 math-site。本地地址为 http://127.0.0.1:52186/，使用图形界面不需要模型 API key。

四个模块分别演示曲面截面、坐标投影、3×3 线性变换、SC/BCC/FCC 晶格及晶面。输入、采样和表达式语法有范围限制，数值秩不能视为精确符号结论。

这是持续迭代的个人作品，开发使用了 Claude、Codex 等 AI 编程助手。公开版不包含个人云端部署配置，也没有自动发布或更新既有线上版本。
